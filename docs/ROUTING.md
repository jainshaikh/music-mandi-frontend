# Routing

## Ownership

```text
Public        /
Auth          /auth/*
Artist        /artist/*
Advertiser    /advertiser/*
Admin         /admin/*
Legacy        temporary mappings (see docs/LEGACY_MIGRATION.md)
```

Artist, Advertiser, and Admin routes must never mix. There is no shared generic `/dashboard/*` route.
